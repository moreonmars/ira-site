# Сайт Іри Харламової

Портфоліо перформанс-артистки: HTML/CSS/JS без збірки, дві мови (укр у корені, англ у `/en`), власна адмінка на Vercel Functions + Blob. Контент робіт і профілю — у `content.json`, адмінка публікує його комітом через GitHub API.

## Не чіпати

- **Шапка сайту.** `.site-header` — фіксована, прозора, з `mix-blend-mode: difference`. Вона візуально накладається на текст, який проїжджає під нею. Це задум, а не баг: не давати їй фон, не ховати при скролі, не «виправляти» під час сусідніх правок.
- **Пошта для входу в адмінку.** `ADMIN_EMAIL` (і запасне значення в `api/admin/login.js`, підставлене значення в `admin/login.html`, згадка в `admin/README.md`) — це облікові дані, а не контакт. Не міняти без прямого прохання: помилка тут закриває Ірі доступ до адмінки.

## Корисно знати

- **Публічна пошта** — `hello@irakharlamova.com`. Джерело правди — `content.json` (`profile.email`); у коді є запасні значення на випадок, якщо JSON не завантажиться.
- **CV** лежить на Google Диску, посилання в `content.json` (`profile.cv`). У репозиторії файла немає і не треба — раніше там був PDF на 55 МБ.
- **Колір панелі браузера** скрізь рожевий (`#ff5cad`). Safari бере колір з фону `body`, тому `body` рожевий, а вершковий малює `main`. Якщо додаєш секцію без власного фону — перевір, чи не просвічує рожевий.
- **Локальний перегляд:** `npx serve` через `.claude/launch.json`. Він ріже `?query` з адрес, тому сторінки виду `work.html?id=...` локально не відкриваються — це вада сервера, не сайту.
