# Ira Kharlamova

Portfolio website of performance artist Ira Kharlamova: [irakharlamova.com](https://irakharlamova.com)

- Ukrainian and English versions.
- Hand-written HTML, CSS and JavaScript, no framework.
- A small admin panel, so Ira adds and edits works herself. Vercel Functions handle sign-in and publishing, images go to Vercel Blob, content lives in `content.json`.

Designed and built by Denys Vasyliuk, [MOONAGE](https://moonage.me/work/ira-kharlamova).
